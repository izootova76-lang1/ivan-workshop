# Иван — видео Мастерской

1080 × 1920, 9:16, 30 fps, 28 секунд, 7 сцен.

Источник: dist/ из коммита 1b03153711bc79092b1d3f9febfc11b6df0fbc92. Сайт не изменён.
source-verification.json: все опубликованные файлы совпадают (текст с учётом CRLF/LF), работают пять блоков, жёлтая зона и шестишаговый тест. Нет ошибок JS и мобильного переполнения. Браузерная проверка опубликованной страницы использует реальные ответы HTTPS, подставленные через маршрутизацию: прямое соединение Edge с Pages сбрасывалось.

Запуск:
    npm ci
    npx remotion studio --no-open
Открыть адрес из терминала, композицию Ivan-Vertical. Отдельные сцены доступны в Scenes.
Проверка: npm run lint
Рендер: npx remotion render Ivan-Vertical out/ivan-workshop-vertical.mp4 --codec=h264 --crf=18

Сцены:
0–2,5: Знакомьтесь, Иван.
2,5–6: AI-помощник для диагностики каналов.
6–13: Пять блоков.
13–17: Четыре цветовые зоны.
17–20: Жёлтая: основа есть, пора связать детали.
20–25: Настоящий Иван строже, на слово не верит.
25–28: Ему подавай доказательства.

Сокращённый текст согласован пользователем для 28 секунд:
«Знакомьтесь, Иван. Мой AI-помощник для диагностики каналов. Ему важна не красота, а ясность: кто вы, логика контента, что можно получить, доверие и готовность к автоматизации. Потом появляется зона: красная, жёлтая, зелёная или синяя. В жёлтой основа есть — пора связать детали. Но настоящий Иван строже. На слово не верит. Ему подавай доказательства».

Голос: Microsoft Dmitry Neural, немного повышенная высота. Синтетический голос; теплоту и иронию нужно оценить при прослушивании. Музыки нет. Дорожка public/ivan-voice.wav; интервалы public/voice-v2/timing.json. Рот имеет три состояния по RMS-громкости, без фонемного lip sync.
Повторная генерация: Python с numpy, pip install --target .tools edge-tts imageio-ffmpeg, затем python scripts/voice.py (интернет). Для просмотра и рендера Python не нужен.

Иван и мастерская — одна картинка. Исходник не деформируется. Анимированы экран лица (редкое моргание, изменение глаз, рот) и свечение антенны. Камера мягко приближается к целой иллюстрации.
Кивки, движение корпуса и жесты требуют слоёв в исходном ракурсе и освещении: интерьер с восстановленным фоном за Иваном, корпус и шея, голова с антенной и пустым экраном, отдельные руки либо готовые позы, передний план со столом и ноутбуком. Нужно восстановить скрытые области у суставов.
